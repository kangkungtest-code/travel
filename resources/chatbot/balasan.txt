# ================================================================
#  File balasan chatbot. Tulisan {toko} otomatis diganti nama toko.
# ================================================================
#  Cara menulis:
#  - Satu topik diawali baris "== nama-topik" (huruf kecil, tanpa spasi).
#  - "kata:" berisi kata kunci, dipisah koma. Boleh campur 3 bahasa.
#    Makin banyak kata kunci yang cocok, makin besar peluang topik ini dipilih.
#  - "tanya.id / tanya.en / tanya.zh_TW": pertanyaan contoh, muncul sebagai
#    tombol saran. Boleh dikosongkan kalau topik ini tidak perlu jadi tombol.
#  - "jawab.id / jawab.en / jawab.zh_TW": jawaban. Kalau jawaban lebih dari satu
#    baris, baris lanjutan diawali spasi.
#  - "admin: ya" berarti di bawah jawaban muncul tombol WhatsApp / LINE admin.
#  - Baris yang diawali # adalah catatan, tidak dibaca chatbot.
#  - Topik "sapaan" muncul saat chat dibuka, "tidak-ketemu" dipakai kalau
#    tidak ada topik yang cocok. Keduanya wajib ada.
# ================================================================
